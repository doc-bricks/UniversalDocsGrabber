# Microsoft Store Listing: UniversalDocsGrabber

## Deutsch (DE-DE)

### Titel
UniversalDocsGrabber

### Kurzbeschreibung
Automatisierte Extraktion und Archivierung von E-Mail-Dokumenten und Anhängen direkt auf Ihrem Gerät.

### Vollständige Beschreibung
UniversalDocsGrabber ist Ihr lokales Werkzeug zur automatisierten Erfassung, Konvertierung und Archivierung von Dokumenten aus Ihren E-Mail-Postfächern.

Wichtigste Merkmale:
- **Lokale Datenhoheit:** Alle Abrufe, Filterungen und Speicherungen erfolgen 100% lokal auf Ihrem Rechner. Es werden keine Daten an externe Server gesendet.
- **Sichere Authentifizierung:** Passwörter werden im Windows Anmeldeinformations-Tresor (Credential Manager) gesichert.
- **Vielseitige IMAP-Unterstützung:** Kompatibel mit gängigen IMAP-Anbietern sowie Gmail-Spezialfiltern.
- **Dokumenten-Konvertierung:** Automatische Erstellung von PDF-Volltexten aus E-Mail-Bodys und Konvertierung gängiger Dateiformate.
- **Intelligente Deduplizierung:** Erkennung identischer Dokumente anhand von SHA-256 Hashwerten.
- **Redigierter Export:** Erzeugt datenschutzkonforme JSON-Bibliotheksauszüge für den lokalen Web/PWA-Companion ohne Weitergabe sensibler Zugangsdaten.

## English (EN-US)

### Title
UniversalDocsGrabber

### Short Description
Automated retrieval and local archiving of email documents and attachments on your PC.

### Full Description
UniversalDocsGrabber is a privacy-first desktop application that automatically retrieves, converts, and organizes documents from your email inboxes into local folders.

Key Features:
- **Local-First Privacy:** All downloads, parsing, and storage remain entirely local on your machine with zero data egress.
- **Secure Keyring Storage:** Credentials are protected using the built-in Windows Credential Vault.
- **Broad IMAP Compatibility:** Connects with standard IMAP servers and supports advanced Gmail filter queries.
- **Document Conversion:** Converts email bodies and common file formats into searchable PDFs.
- **Hash Deduplication:** Identifies duplicate documents across runs using SHA-256 checksums.
- **Redacted Companion Export:** Generates privacy-safe library snapshots for mobile PWA companion auditing without exposing credentials or sensitive message content.
