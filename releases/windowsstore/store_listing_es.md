Kurzbeschreibung:
Extracción automatizada y archivo local de documentos y archivos adjuntos de correo electrónico.

Beschreibung:
UniversalDocsGrabber es una aplicación de escritorio local diseñada para la extracción, conversión y archivado seguro de documentos desde buzones de correo electrónico.

- Privacidad Local Total: Todas las descargas, filtros y guardados se realizan 100% localmente sin salida de datos externos.
- Autenticación Segura: Las credenciales se resguardan de manera cifrada en el Administrador de credenciales de Windows.
- Compatibilidad IMAP Universal: Admite proveedores de correo estándar y consultas de filtrado avanzadas.
- Conversión de Documentos: Genera archivos PDF con texto completo a partir de correos y convierte formatos estándar.
- Deduplicación Inteligente: Detecta duplicados mediante sumas de verificación SHA-256.
- Exportación Redactada: Crea resúmenes de biblioteca en JSON para el acompañante Web/PWA sin revelar credenciales.

Zielgruppe:
Autónomos, profesionales independientes, departamentos de contabilidad y usuarios que desean extraer y archivar documentos y facturas automáticamente y de forma 100% local.

Schlüsselwörter:
documentos, adjuntos, facturas, archivo, correo, pdf, extraccion
