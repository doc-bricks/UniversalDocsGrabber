1. PRODUCT POSITIONING & VALUE PROPOSITION
--------------------------------------------------------------------------------
UniversalDocsGrabber is a local-first, privacy-respecting Windows email attachment
downloader, OCR processor, and document categorization workbench with a static,
redacted Web/PWA companion for cross-device mobile document review.

Core Value Pillars:
1. Zero-Egress Privacy: Runs 100% locally on user hardware. Credentials stay in
   the Windows Credential Vault. Zero cloud analytics or unsolicited network traffic.
2. End-to-End Mail Ingestion: Connects via IMAP/Gmail (with X-GM-RAW support),
   extracts attachments and text bodies, converts Office/Text to PDF, applies
   Tesseract OCR to scans, and deduplicates via SHA-256 content hashes.
3. Decoupled Web/PWA Companion: Generates a sanitized, redacted JSON export
   (docsgrabber-library-v1.json) with ZERO credentials or mail bodies for safe,
   offline mobile review and document triage.
4. Autonomous Automation: Background scheduler (15 min to 24 h) with conflict
   guarding and batch processing across multiple mail accounts.

2. TARGET AUDIENCE & PERSONAS
--------------------------------------------------------------------------------
Persona 1: Solo Entrepreneurs & Small Business Bookkeepers
- Pain Point: Invoices, tax receipts, and payment confirmations scattered across
  multiple business and personal email inboxes; manual downloading is tedious.
- Solution: Automated scheduled IMAP polling with rule-based auto-categorization
  for 'Rechnungen', 'Steuer', and 'Bank' directly into date-organized folders.

Persona 2: Legal, Tax & Compliance Assistants
- Pain Point: Need strict local custody of client documents, signed contracts,
  and insurance notices without uploading confidential emails to third-party cloud SaaS.
- Solution: 100% offline document parsing, Tesseract OCR for searchable PDFs,
  and SHA-256 deduplication to guarantee data integrity without external data egress.

Persona 3: Privacy-Conscious Power Users & Document Archivists
- Pain Point: Desire a clean, indexed desktop document archive with the ability
  to review document metadata on a tablet or phone without installing heavy mail clients.
- Solution: Static Web/PWA companion reading a redacted JSON export with zero
  passwords or mail bodies, usable offline via Service Worker.

Persona 4: Local-First AI & Automation Engineers
- Pain Point: Ingestion pipelines require structured, sanitized metadata feeds
  without risking API credential leaks or large binary payload crashes.
- Solution: Standardized docsgrabber-library-v1.json schema, documented llms.txt,
  and clean local CLI / Python invocation hooks.

6. GOVERNANCE & RUNTIME INVARIANTS (INV-LOCAL-01 to INV-SLA-10)
--------------------------------------------------------------------------------
INV-LOCAL-01: 100% Local Processing — All IMAP ingestion, parsing, PDF rendering,
              and OCR tasks execute exclusively on local hardware. Zero network egress.
INV-SEC-02:   RunAsInvoker Privilege Boundary — Operates strictly in unprivileged
              user space. Never requests or requires administrative elevation.
INV-CRED-03:  OS Credential Protection — Passwords and secrets are stored in the
              Windows Credential Vault via keyring. Never stored in plain text.
INV-REDACT-04:Sanitized Mobile Export — docsgrabber-library-v1.json strictly omits
              passwords, IMAP server host secrets, mail bodies, and raw documents.
INV-HASH-05:  SHA-256 Deduplication — Files are fingerprinted by cryptographic hash
              prior to filesystem writes to prevent duplicate storage.
INV-FALL-06:  Graceful Degradation — If Microsoft Word OLE, Poppler, or Tesseract are
              missing, clear informative logs are issued without fatal process crashes.
INV-PWA-07:   Zero External PWA Dependencies — Static companion runs purely on native
              DOM, native Service Worker, and local CSS/JS. Zero CDN dependencies.
INV-LIC-08:   100% Permissive Open Source — Verified MIT project license with LGPLv3
              dynamic linking transparency and user library replacement freedom.
INV-SLA-09:   48-Hour Security Response SLA — Security inquiries acknowledged within
              48 hours; triage completed within 5 business days.
INV-PAR-10:   Bilingual Parity — Full functional and structural parity across English
              and German documentation, navigation anchors, and contract tests.
