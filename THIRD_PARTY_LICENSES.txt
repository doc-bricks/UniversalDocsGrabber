## Audit Notes & License Compatibility Verification

1. **Permissive Project Licensing (MIT-Lizenz):**
   UniversalDocsGrabber is released under the MIT License. All direct runtime Python dependencies (pypdf, reportlab, Pillow, xhtml2pdf, keyring, pytesseract, pdf2image, docx2pdf, pywin32) are licensed under permissive open-source licenses (MIT, BSD-3-Clause, Apache-2.0, PSF-2.0, HPND). There are zero copyleft violations.

2. **Qt & LGPL-3.0 Dynamic Linking (dynamische Bindung):**
   PySide6 and Qt6 libraries are loaded dynamically as shared objects / DLLs. In accordance with the LGPL-3.0 terms, users are free to replace or relink the Qt runtime libraries. The application code itself remains under its independent MIT license.

3. **Subprocess Isolation for External Tooling (Subprozess-Isolation):**
   External tools such as Tesseract OCR (Apache-2.0) and Poppler (GPL-2.0-or-later) run strictly as independent operating system child processes. Communication occurs exclusively through standard command-line arguments and temporary files on disk. There is no in-process dynamic or static linking, ensuring clean license boundaries.

4. **PyInstaller Bootloader Exception (Bootloader):**
   Binary distributions generated via PyInstaller utilize the unmodified Bootloader under the official PyInstaller Bootloader Exception, granting permission to license and distribute the bundled executable under the terms of the project's own MIT License.

5. **Security Vulnerability Scans (Stand: 2026-09-30):**
   All dependency floors have been hardened against known CVEs:
   - `pypdf>=4.0.0` protects against legacy PyPDF 3.x parser DoS issues.
   - `Pillow>=10.4.0` protects against libwebp/image parser vulnerabilities (CVE-2023-44271, CVE-2024-28219).
   - `keyring>=25.0.0` ensures modern Windows Credential Vault interaction.
   - `pytest>=9.1.1` protects against CVE-2025-7117.
   - `ruff>=0.9.0` ensures contemporary code quality and AST security auditing.

- **Zero-Copyleft Isolation Guarantee (INV-LIC-08)**: Sämtliche Laufzeitabhängigkeiten sind permissiv lizenziert (MIT, BSD-3-Clause, Apache-2.0, PSF) oder unterliegen der LGPL-3.0 mit dynamischer Bindung. Es besteht kein viraler Copyleft-Einfluss auf abgeleitete Werke.
- **Zero-Egress Offline Verification Notice**: Alle Ingestions-, OCR- und Parsing-Prozeduren laufen hermetisch lokal ab. Zu keinem Zeitpunkt werden E-Mail-Inhalte, Anmeldedaten oder Dokumente an externe Server übermittelt.
