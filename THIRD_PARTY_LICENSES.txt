## Audit Notes

- The declared MIT project license is compatible with the permissive direct
  dependencies. Distributions that include Qt for Python must preserve the
  applicable LGPL notices and license terms for the dynamically linked Qt
  components.
- OSV queries on 2026-08-03 returned no entries for current checked releases
  `pypdf==6.14.2`, `Pillow==12.3.0`, and `xhtml2pdf==0.2.17`. The much older
  allowed minima in `requirements.txt` did return entries and therefore remain
  a dependency-policy follow-up. They were not mass-upgraded in this audit
  because the repository still declares Python 3.8 support and the safe current
  pypdf/Pillow releases require newer Python versions.
- Optional external tools such as Tesseract OCR, Poppler, and Microsoft Word are
  runtime/system prerequisites, not Python packages shipped by this project.
- Preserve upstream license files and notices bundled inside installed wheels
  and source distributions.
- Re-run this inventory when `requirements.txt`, `web_companion/package.json`,
  or the frozen build environment changes.
