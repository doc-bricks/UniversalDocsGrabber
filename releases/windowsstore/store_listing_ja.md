Kurzbeschreibung:
メール文書や添付ファイルを安全にローカル保存・自動抽出するデスクトップツール。

Beschreibung:
UniversalDocsGrabber は、メールボックスから文書や添付ファイルを自動で収集、変換、整理するプライバシー重視のデスクトップアプリケーションです。

- 完全ローカル処理：メールの取得、抽出、保存はすべてPC上で完結し、外部サーバーへのデータ送信は一切ありません。
- 安全な認証情報管理：パスワードは Windows 資格情報マネージャーにより暗号化保管されます。
- 幅広い IMAP 対応：標準的な IMAP サーバーおよび柔軟な検索フィルターに対応しています。
- ドキュメント変換：メール本文や各種添付ファイルを自動で検索可能な PDF 形式に変換します。
- 重複排除：SHA-256 ハッシュ値を用いて重複ファイルを正確に検出・除外します。
- 編集済みエクスポート：認証情報を一切含まない安全な JSON ライブラリを出力し、Web/PWA コンパニオンで確認可能です。

Zielgruppe:
個人事業主、経理担当者、オフィスユーザー、および受信した請求書や重要文書を安全にローカル保存したいパワーユーザー。
